## 3. 关键痛点汇总(对我们做 AIchat-Hub 的直接指引)

| 痛点 | 频率 | 我们的解法 |
|---|---|---|
| **不知道该选哪个模型** | ★★★★★ | 一键横向对比 N 个模型 |
| **月度成本不可控** | ★★★★ | 实时 token 计数 + 单价换算 |
| **多模型切换繁琐** | ★★★★ | 一个 CLI/Web 聚合所有模型 |
| **国产模型覆盖差** | ★★★ | 深度集成 DeepSeek/Kimi/智谱/通义 |
| **上下文衰减** | ★★★ | 自动摘要压缩 + 关键信息高亮 |
| **隐私担忧** | ★★ | 本地化处理,API key 不上传 |
