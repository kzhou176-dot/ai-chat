## 2. 行业核心维度(5 维评估)

### 维度 1:入门门槛
- **算法**:985/211 是底线,ACM/数学建模/顶会论文加分
- **产品**:学历宽松,但要求"产品感"(用户洞察 + 数据驱动)
- **运营**:学历最宽松,小红书/B 站/抖音 个人号是硬通货
- **设计**:作品集 = 一切(实习 + 个人项目)
- **数据**:统计学/计算机/数学背景优先
- **金融**:顶级学校 + 头部实习(中金/中信暑期)
- **咨询**:清北复交 + MBB 案例面试
- **快消**:宝洁八大问是经典
- **地产**:工程类(土木/建筑)专业优先

### 维度 2:典型职业路径(3-5 年)
- **算法**:校招 P5 → P6 (3 年) → P7 (5 年) → 资深/专家
- **产品**:产品助理 → 产品经理 → 高级 → 产品总监
- **运营**:运营专员 → 运营经理 → 运营总监
- **设计**:初级设计师 → 高级 → 设计专家 / 设计总监
- **数据**:分析师 → 高级分析师 → 数据科学家 / 经理

### 维度 3:核心技能树
- **算法**:Python/PyTorch/LeetCode/论文/数学
- **产品**:用户调研/PRD/Axure/数据 SQL/竞品分析
- **运营**:内容/活动/用户增长/数据分析/小红书
- **设计**:Figma/Sketch/UI 规范/交互/动效
- **数据**:SQL/Python/Excel/Tableau/A-B 测试
- **金融**:Excel/Wind/Bloomberg/估值/财务建模
- **咨询**:PPT/案例分析/行业研究/用户访谈
- **快消**:商业思维/宝洁八大问/英语/数字营销
- **地产**:成本管理/工程管理/营销策划/投融资

### 维度 4:2025 校招趋势
- **算法**:LLM/多模态/AIGC 是新风口,具身智能初露头角
- **产品**:AI 产品经理需求激增(从 0 到 1 的 AI 应用)
- **运营**:内容运营 / 短视频运营 / 增长运营 三足鼎立
- **设计**:AI 辅助设计普及,但 UX 研究 / 用户洞察更值钱
- **数据**:与算法边界模糊,"数据 + 业务"复合型人才更受欢迎
- **金融**:投行降薪,资管/量化仍是香饽饽
- **咨询**:战略咨询仍卷,数字化咨询是新增量
- **快消**:管培生项目仍是顶级,但 3-5 年留存率 < 30%
- **地产**:整体收缩,但"代建/物业/商业"细分还在招

### 维度 5:典型一天(What's the real job)
- **算法**:80% 写代码 + 调参 + 跑实验;20% 开会 + 写文档
- **产品**:50% 开会(对齐/评审)+ 30% 写 PRD + 20% 调研
- **运营**:40% 数据 + 30% 写文案/活动 + 30% 沟通协调
- **设计**:60% 画图 + 30% 评审 + 10% 用户研究
- **数据**:50% 写 SQL/Python + 30% 报告 + 20% 业务沟通
- **金融**:60% Excel/PPT + 30% 会议 + 10% 客户沟通
- **咨询**:70% PPT + 25% 客户访谈 + 5% 数据
- **快消**:30% 会议 + 30% 跨部门协作 + 20% 数据 + 20% 活动
- **地产**:40% 现场 + 30% 会议 + 20% 文档 + 10% 销售

## 3. 共性短板(我们能补的)

### 短板 1:无"过来人"对话
- 知乎/小红书是经验贴,但无法实时追问
- 学生想了解"算法岗真实一天"找不到对口的人

### 短板 2:行业信息碎片化
- BOSS 直聘的"职位描述" + 知乎的"职业规划"分散在不同平台
- 没有统一的"行业画像"+"职业路径"+"薪资"数据库

### 短板 3:无基于 Holland Code 的推荐
- 测出来是 IAS,不知道哪个行业最适合
- 没有"IAS 适合互联网产品/咨询"这种映射

### 短板 4:无虚拟人对话
- 静态报告不能"追问"
- 学生关心"我这种背景能进大厂吗?",报告不能回答

## 4. AIchat-Hub `scripts/industry_insight.py` 设计要点

### 9 大行业专家(虚拟人)
| ID | 行业 | 头像 emoji | 关键问题库 |
|---|---|---|---|
| algorithm | 算法工程师 | 🤖 | 30+ 题 |
| product | 产品经理 | 📱 | 30+ 题 |
| operation | 运营 | 📊 | 25+ 题 |
| design | UI/UX 设计 | 🎨 | 25+ 题 |
| data | 数据分析师 | 📈 | 25+ 题 |
| finance | 金融 | 💰 | 25+ 题 |
| consulting | 咨询 | 🏢 | 25+ 题 |
| fmcg | 快消 | 🛒 | 20+ 题 |
| realestate | 地产 | 🏗️ | 20+ 题 |

### 每个专家提供
1. **行业画像**:公司类型 / 头部公司 / 校招薪资
2. **职业路径**:3-5 年典型路径
3. **技能树**:必备技能
4. **常见问题库**:30+ FAQ(类似 interview 的题库)
5. **基于 Holland Code 的匹配度**:复用 career_profile 的 RIASEC

### 5 维评分(类似 interview.py)
- 复用 interview 模块的 5 维评分逻辑(逻辑/表达/技术深度/应变/匹配度)
- 每个回答自动评分

### 与 career_profile.py 联动
```python
# 用户 Holland Code = "IAS"
# 推荐行业:
#  - consulting (IES) 匹配度 = 0.8
#  - product (EAS) 匹配度 = 0.6
#  - fmcg (SAE) 匹配度 = 0.5
```

### 沙箱安全
- 9 行业 + 30+ FAQ/行业 = 200+ 题目静态库
- 评分用规则化(复用 interview 5 维)
- 不依赖 LLM API
