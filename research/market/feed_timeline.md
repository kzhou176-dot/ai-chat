## 2. 大学生 Feed 需求

### 需求 1:同校同专业的"过来人"经验
- LinkedIn 退出后,这块没人做
- 想要"清华 CS 2023 届学长分享字节面试经验"这种垂直内容

### 需求 2:行业第一手信息
- "算法岗 2025 校招薪资 30-60 万" 这种行业情报
- 行业专家虚拟人定期发布

### 需求 3:校招时间线
- 7-8 月提前批 / 9-10 月正式批 / 11 月补录
- 各家公司投递截止时间提醒

### 需求 4:无算法压力
- 不希望被算法"信息茧房"
- 想要"有意义的内容"而非"刷不完的短视频"

## 4. 共性短板(我们能补的)

### 短板 1:无校友垂直度
- 小红书/知乎内容散乱,找不到"同校同专业学长"
- 校友身份无验证,内容真伪难辨

### 短板 2:无行业系统化
- 知乎是问答,即刻是短评,缺乏系统化"行业全景"
- 学生需要"入门 → 进阶 → 专家"递进式内容

### 短板 3:无时间线
- 校招/笔面试/AST 时间散落
- 没有"距离投递截止还有 X 天"这种提醒

### 短板 4:无个性化
- 千人一面,算法推荐只看你看过的
- 没有"基于你的 Holland Code / 目标行业"推荐

## 5. AIchat-Hub `scripts/feed.py` 设计要点

### 5.1 4 类 Feed 内容
- **校友动态**(alumni_post):学长学姐发的内推/经验
- **行业洞察**(industry_post):9 行业专家发的行业情报
- **求职技巧**(career_post):简历/面试/职业规划技巧
- **校招资讯**(recruit_post):校招时间线/公司宣讲/笔试真题

### 5.2 FeedItem 数据模型
- id / author_id / author_name / author_role / author_avatar
- content(纯文本)
- timestamp
- category(4 类)
- tags(关键词列表)
- likes / comments / shares(互动数)
- liked(用户是否点过)
- industry(关联行业,可选)
- school(关联学校,可选)

### 5.3 核心 API
- `publish_post()` — 发布
- `like_post()` / `unlike_post()` — 点赞
- `add_comment()` — 评论
- `list_feed(filter, sort, limit)` — 时间线
- `recommend_for_user(holland_code, target_industry)` — 个性化推荐

### 5.4 个性化推荐
- 基于 Holland Code:IAS → 推荐咨询/产品/算法
- 基于 target_industry:算法 → 推荐算法相关内容
- 基于 school:清华 → 推荐清华校友内容

### 5.5 沙箱安全
- 30+ 静态 Feed(混合 4 类)
- 纯规则点赞/评论(内存存储)
- 不依赖 LLM
