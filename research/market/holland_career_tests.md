## 1. 霍兰德理论背景

### RIASEC 6 维
| 字母 | 英文 | 中文 | 关键词 | 典型岗位 |
|---|---|---|---|---|
| **R** | Realistic | 实际型 | 动手 / 操作 / 工具 / 机械 | 工程师 / 技工 / 户外作业 |
| **I** | Investigative | 研究型 | 研究 / 分析 / 思考 / 探索 | 科学家 / 算法 / 研究员 |
| **A** | Artistic | 艺术型 | 创造 / 表达 / 艺术 / 设计 | 设计师 / 艺术家 / 文案 |
| **S** | Social | 社会型 | 助人 / 教育 / 服务 / 社交 | 教师 / 咨询 / HR / 医生 |
| **E** | Enterprising | 企业型 | 领导 / 影响 / 说服 / 管理 | 销售 / 创业者 / 高管 |
| **C** | Conventional | 常规型 | 组织 / 数据 / 流程 / 规范 | 会计 / 行政 / 运营 |

### Holland Code
- 取分数最高 3 个维度组成 3 字母代码
- 例:研究型+艺术型+社会型 = "IAS"
- 60+ 种代码组合,每种对应一类职业群

### 权威性
- John Holland 1959 年提出,1997 年 SDS(Self-Directed Search) 标准化
- 学术界广泛使用,大公司招聘常用
- 60 题版本最经典,简版 30 题,扩展版 120 题

## 3. 共性短板(我们能补的)

### 短板 1:静态结果,无动态对话
- 大多数工具就是"60 题 → 1 份报告"完事
- 没有"基于结果的虚拟人对话"("你的代码是 IAS,要不要聊聊为什么?")
- 学生看到"IAS"3 个字母还是懵,需要人解读

### 短板 2:无岗位推荐细化
- 给的是"艺术家 / 设计师"这种大类
- 没有"互联网产品经理 / 增长运营 / 数据分析师"这种细分岗位映射
- 学生不知道具体能投哪些校招岗位

### 短板 3:无简历 / 面试联动
- 测完了就完了
- 没和"我的简历项目"对照("你测出来是 I,但你简历全是 S 类项目,要不要考虑往 I 方向调整")

### 短板 4:无跟踪对比
- 测一次就一次
- 没有"上次 vs 这次"对比
- 学生不知道自己的兴趣是否在变化

## 4. AIchat-Hub `scripts/career_profile.py` 设计要点

### 内置题库
- **60 题**(标准霍兰德,10 题/维)
- 答题模式:喜欢(+2) / 中立(+1) / 不喜欢(0)
- 中文表述,贴近大学生语境(用"算法工程师"等具体岗位名)

### 6 维评分 + Holland Code
- 6 维分数(0-20)
- 取 Top 3 组成代码(例 "IAS")
- 自动识别"RIASEC 经典代码"(30+ 种已映射职业群)

### 数字人"职业规划师"解读
- 角色:`career_guide`(职业规划师 🧭)
- 风格:引导式对话,基于分数解读
- 输出:
  1. 6 维分数条形图
  2. Holland Code + 含义
  3. 推荐岗位(细到校招级别)
  4. 学习路径建议
  5. 行业/公司类型推荐

### 沙箱安全
- 题库 + 评分用纯规则
- 不依赖 LLM API
- 可选 LLM 解读(接 LLMClient,无 key 也 OK)
