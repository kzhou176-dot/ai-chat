# 中国大学生求职需求画像(2024-2026)

> 方向调整时补充调研,cycle 10.5
> 用途:为"虚拟人功能设计"提供用户需求基线

---

## 1. 目标用户分层

### 大一-大二(探索期)
- **核心需求**:专业认知、兴趣探索、初步实习
- **痛点**:
  - 不了解"我这个专业以后能干啥"
  - 没渠道接触行业真实工作场景
  - 不知道该学什么技能
- **适合的虚拟人**:
  - 职业探索引导(霍兰德兴趣测试)
  - 同专业学长学姐
  - 行业概览(算法/产品/运营/设计/金融/咨询 等)

### 大三-大四(求职期)
- **核心需求**:校招、简历、面试、offer 选择
- **痛点**:
  - 简历空白,不知道怎么写
  - 笔试 / 面试没经验
  - 多个 offer 不知道怎么选
  - 海投石沉大海,没反馈
- **适合的虚拟人**:
  - 模拟面试官(按行业 / 公司定制)
  - AI 简历生成 + 评分 + 改写
  - HR 顾问(行业薪资、岗位画像)
  - 校友内推助手

### 研究生 / 应届(冲刺期)
- **核心需求**:实习转正、垂直行业深度、读研 vs 工作
- **痛点**:
  - 实习 vs 论文冲突
  - 算法 / 后端 / 数据 等垂直技能需要深挖
  - 不知道怎么选第一份工作
- **适合的虚拟人**:
  - 行业专家(算法、产品、运营)
  - 资深 HR(谈薪策略)

## 2. 关键场景(优先级排序)

| 优先级 | 场景 | 频次 | 现有产品覆盖 |
|---|---|---|---|
| P0 | **简历生成 / 改写 / 评分** | 高 | 弱(只有模板) |
| P0 | **模拟面试**(技术 / 行为 / HR) | 高 | 几乎无 |
| P1 | **职业画像 / 兴趣测试** | 中 | 弱 |
| P1 | **行业洞察对话**(产品/算法/运营) | 中 | 无 |
| P1 | **校友内推** | 中 | 弱 |
| P2 | **简历真实性互验**(轻量学号认证) | 低 | 无 |
| P2 | **海归/外企专版** | 低 | 无 |

## 3. 详细用户故事(User Stories)

### Story 1:大三学生小王
> "我是计算机专业大三,准备找暑期实习,但简历一片空白,不知道算法岗 vs 后端岗哪个适合我。"
- **触发**:看到虚拟人"算法小助手" / "后端小助手"
- **对话**:
  - 学生:我是 985 计算机大三,学过数据结构、操作系统,会一点 Python
  - 虚拟人:你考虑过算法岗还是后端岗吗?我先问你几个问题...
  - 虚拟人:看起来你更适合后端实习,这里有 5 个常见面试问题,我先做一次模拟面试看看你的水平
- **输出**:岗位推荐 + 模拟面试反馈

### Story 2:大四学生小李
> "我投了 30 家公司,只有 3 家给了面试,但都挂在二面,不知道哪里出问题。"
- **触发**:模拟面试官"阿里 HR 风格" / "字节技术面风格"
- **对话**:
  - 虚拟人:请介绍你最有成就感的一个项目
  - 学生:...(回答)
  - 虚拟人:你的回答缺少量化数据,建议补充"性能提升 30%"这类硬指标,另外 STAR 法则(情境/任务/行动/结果)没组织好
- **输出**:面试评分 + 改进建议

### Story 3:研一学生小张
> "我是 211 控制工程研一,导师让我搞强化学习,但我不确定这方向就业好不好。"
- **触发**:行业专家"算法工程师 / 强化学习方向"
- **对话**:
  - 学生:强化学习现在就业情况怎么样?和大模型哪个方向更好?
  - 虚拟人:从 2024 年看,RL 偏研究,LLM 偏工程,后者岗位多 5-10 倍,但竞争也大。如果你目标是工业界,建议...
- **输出**:行业画像 + 技能树 + 学习路径

### Story 4:海归留学生小赵
> "我英国硕士毕业回国,不知道国内互联网公司校招流程,也不知道薪资范围。"
- **触发**:HR 顾问"互联网校招"
- **对话**:
  - 学生:英国硕士能参加 2025 届校招吗?BAT 算法岗薪资多少?
  - 虚拟人:可以,但时间线要早准备(7-8 月提前批)。BAT 算法岗 25-50 万年薪(看评级),我帮你做个时间规划...
- **输出**:校招时间线 + 薪资指南 + 准备清单

## 4. 核心功能设计

### 功能 1:简历生成 / 改写
- **输入**:学生基本信息(学校/专业/项目/技能/实习)
- **处理**:
  - 提取关键词(岗位画像匹配)
  - 量化改写(动词 + 数字)
  - STAR 法则结构化
- **输出**:3 份不同侧重(技术 / 产品 / 运营)的简历

### 功能 2:模拟面试官(多角色)
- **角色库**:
  - 技术面试官(算法/后端/前端/数据/测试)
  - 行为面试官(STAR 法则)
  - HR 面试官(谈薪 / 文化匹配)
  - 压力面面试官
- **能力**:
  - 提问题(按岗位 / 公司)
  - 评分(逻辑/表达/技术深度/应变)
  - 反馈(具体改进建议)
  - 复盘(完整对话可回放)

### 功能 3:职业画像 / 兴趣测试
- **测试**:霍兰德职业兴趣测试(Holland Code: RIASEC)
- **维度**:实际型 / 研究型 / 艺术型 / 社会型 / 企业型 / 常规型
- **输出**:6 维分数 + 推荐岗位 + 虚拟人对话式解读

### 功能 4:行业洞察对话
- **专家库**:算法/产品/运营/设计/数据/金融/咨询/快消/地产
- **能力**:
  - 回答"这个岗位日常到底做什么"
  - 分享"职业路径 / 技能树 / 薪资天花板"
  - 答疑"我适合这个方向吗"
- **形式**:长对话 + 关键问答卡

### 功能 5:校友内推助手
- **机制**:同校 + 同专业 + 已就业校友(经授权)的虚拟人
- **能力**:
  - 介绍公司 / 团队 / 岗位
  - 内推简历(需真人审核)
  - 解答面试问题(非机密)
