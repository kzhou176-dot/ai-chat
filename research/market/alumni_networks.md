## 1. 大学生找校友的 4 大真实痛点

### 痛点 1:同校同专业没人脉
- 找学长学姐只能靠朋友圈/微信群/老乡群
- "同院同专业"垂直度差,大部分求助石沉大海

### 痛点 2:内推渠道不正规
- BOSS直聘 / 智联 都是 HR 视角,不是"同校学长视角"
- LinkedIn 2023-08-09 退出中国大陆后,海归/外企圈层的"找校友"路径断了
- 微信群里"求内推"经常没人回

### 痛点 3:校友身份真实性无法验证
- "我是清华的""我在字节" — 无验证
- 假冒学长学姐骗简历/骗钱时有发生

### 痛点 4:缺乏"过来人"建议
- 内推成功也只是"递简历",没人说"面试官会问什么"
- 没有"基于我背景的校友推荐"这种匹配

- 身份验证弱(假冒学长学姐)

## 3. AIchat-Hub `scripts/alumni.py` 设计要点

### 3.1 4 维匹配
| 维度 | 权重 | 含义 |
|---|---|---|
| **同校** | 0.40 | 学校完全相同 |
| **同院 / 同专业** | 0.30 | 学院或专业匹配 |
| **同行业** | 0.20 | 当前所在公司行业匹配 |
| **同城** | 0.10 | 城市匹配(可选) |

匹配度 = 0.4×校 + 0.3×院 + 0.2×业 + 0.1×城(都是 0/1)

### 3.2 校友池(静态模拟 50+)
- 覆盖:清华 / 北大 / 复旦 / 上交 / 浙大 / 中科大 / 武大 / 哈工大 / 西交 / 南大 等 985
- 专业:CS / 软件 / 通信 / 自动化 / 数学 / 物理 / 金融 / 管理 / 设计 等
- 行业:互联网 / 金融 / 咨询 / 快消 / 国企 / 创业
- 公司:字节 / 阿里 / 腾讯 / 美团 / 百度 / 华为 / 中金 / 高盛 / MBB 等
- 届:2020-2024 毕业(已工作 1-5 年)

### 3.3 虚拟学长学姐(经授权)
- 角色:`senior_dev`(学长工程师 👨‍💻) / `senior_pm`(学姐产品经理 👩‍💼) / `senior_finance`(学长金融)等
- 数字分身:基于校友 Profile,自动生成"虚拟人"对话 Prompt
- 边界:不会替代真人,只做"信息传递 + 模拟对话"
- 沙箱安全:纯规则对话,无 LLM

### 3.4 内推助手
- 状态:requested / accepted / submitted / rejected / passed
- 学生发起"内推请求"→ 虚拟学长学姐(代表真人)接受 → 提交简历 → 状态更新
- 沙箱安全:状态机 + 内存存储

### 3.5 与其他模块联动
```python
# 用户简历 Profile (cycle 11)
# 行业画像 (cycle 14)
# Holland Code (cycle 13)
# → 自动推荐同校 + 同行业 + 匹配度 Top 5 校友
```

### 3.6 身份验证(轻量)
- 学校邮箱格式验证(`@<学校域名>.edu.cn`)
- 模拟数据库:已知 985/211 学校域名清单
