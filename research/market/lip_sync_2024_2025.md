## 2. Wav2Lip 深度(2020 经典)

### 2.1 论文
- **"A Lip Sync Expert Is All You Need for Speech to Lip Generation In The Wild"**
- ACM Multimedia 2020
- 团队:印度海德拉巴大学 + 英国巴斯大学

### 2.2 核心创新
1. **预训练 Expert Lip-sync Discriminator**(唇形同步专家判别器)
   - 训练在真实视频上,不被生成样本污染
   - LRS2 测试集判别准确率 **91%**(LipGAN 仅 56%)
2. **3 个 Loss 加权**:
   - L_recon 重建(主)
   - L_sync 同步(权重 0.03)
   - L_gen 对抗(权重 0.07)
3. **2 个评估指标**:
   - LSE-D(越低越好,真实 ~6-7)
   - LSE-C(越高越好,真实 ~7-8)

### 2.3 局限
- 2D 生成,无 3D 结构
- 侧脸效果差
- 头部运动受限

## 3. SadTalker(CVPR 2023)

- 头部运动生成
- 3D 一致性(相比 Wav2Lip 大幅提升)
- 配合 DAIN 插帧(25fps→50fps)
- 显存中等(RTX 4090)
- 中文社区优化版:SadTalker-Video-Lip-Sync

## 4. MuseTalk(腾讯,2024)

- 8GB 显存即可
- 实时(秒级生成短视频)
- 中文社区热推
- 比 Wav2Lip 效果更好,比 SadTalker 更快

## 5. Live Avatar(阿里,2024-2025,最前沿)

### 5.1 核心创新
- **语音直驱**(无需动捕)
- 16kHz WAV → 带口型+呼吸节奏+情绪微表情的高清视频
- 图像+音频+文本**三输入**
- 提示词引导风格控制(商务/脱口秀/严肃主播)

### 5.2 三层架构
1. **声学特征提取层**:F0 包络 + 能量谱斜率 + 瞬态冲击响应
2. **口型-语音对齐层**:DTW 校准(误差 <0.15s)
3. **表情-语义融合层**:文本向量 × 语音向量 → 一致性表情

### 5.3 中文专项优化
- 汉语声调 / 轻声 / 儿化音
- 日常表达("你好吗?"/"这事儿")自然度超英文模型

### 5.4 硬件硬约束
- **单卡 80GB 显存**(H100/A100)
- 5×4090 不行(FSDP unshard 峰值 25.65GB > 22.15GB)
- 80GB 黄金分辨率:**688×368**

## 6. 关键洞察(对我们做虚拟人 AI chat 的指引)

| 维度 | 主流方案 | 我们的解法 |
|---|---|---|
| **抽象层** | 每个项目独立 API | avatar_video.py 统一抽象(Wav2Lip/SadTalker/MuseTalk) |
| **硬件门槛** | 80GB 高门槛 | mock provider 沙盒可跑(不真合成) |
| **中文优化** | Live Avatar 突出 | 我们不重复造轮子,集成即可 |
| **多输入融合** | 图像+音频+文本 | 我们已具备 Persona + Memory + Scene → 嘴型输入 |
| **TTS → 视频** | 主流都做 | 我们 TTS (cycle 5) → avatar_video (cycle 6) 串联 |
| **批量 vs 实时** | 主流批量 | 留接口未来支持实时(LiveTalking 等) |
