## 4. 关键技术参数(实测)

### 4.1 响应延迟
- **ChatGPT Plus**:平均首 token < 1s,长输出流式
- **GPT-4 Turbo**:4K token 输入 1.2s 响应,16K token 输入 3.9s
- **免费版**:高峰时段排队 + "服务器繁忙"

### 4.2 上下文窗口
- GPT-4o:128K
- GPT-4 Turbo:128K
- o1/o3 系列:200K
- Claude 3.5/4:200K(吊打)

### 4.3 上下文保持(衰减数据)
- 第 10 轮:实体召回率 98.2%,约束满足率 96.7%
- 第 25 轮:实体召回率 51.6%,约束满足率 39.2%(大幅衰减)
- 解决:摘要增强 / 滑动窗口

## 5. 商业化趋势(2026 观察)

- **价格分层**清晰:免费 / 入门 / 标准 / 推理 / 极限(5 档)
- **广告化**开始:免费版 + Go 版将引入对话相关广告
- **SOTA Mode**:Pro 专属"超推理"模式
- **国内镜像版**普及:免 VPN 直连

## 6. 关键洞察(对我们做 AIchat-Hub 的启示)

1. **价格不是壁垒** — 用户对 ¥20-200 都可接受,关键是"值不值"
2. **环境稳定性**是最大痛点 — 封号/限速/排队是用户核心抱怨
3. **多模型对比**是强需求 — 90% 用户想"既要 Claude 写作又要 GPT 编程"
4. **成本可视化** = 差异化 — 没人清楚自己每月花了多少 token 钱
5. **国产模型已具备替代能力** — DeepSeek / Kimi 在中文场景优于 GPT-4
