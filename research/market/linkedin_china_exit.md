## 1. 关键事件

| 时间 | 事件 | 来源 |
|---|---|---|
| 2021-10-14 | 领英中国宣布关闭职业社交平台(InCareer),仅保留"领英职场" | 领英官方公告 |
| 2022-08-09 | "领英职场"宣布将于 2023-08-09 终止服务 | 领英官方公告 |
| 2023-08-09 | "领英职场"正式停服,APP / 桌面端 / 微信小程序全部下线 | 多家媒体报道 |
| 2023-08 至今 | 中国大陆访问 LinkedIn 主站仍需 VPN,服务受限 | 实测 |

**官方退出原因**:
- 中国本地化运营成本高、合规要求趋严(数据本地化、内容审查)
- 微软(Microsoft)2023-02 完成对 LinkedIn 全球业务调整
- "领英职场"模式在中国未能与 BOSS直聘 / 智联招聘 等本土玩家竞争

## 2. 市场空缺分析(退出后留下的 4 大缺口)

### 缺口 1:职业社交网络断层
- 校友关系维护(同校、同院、同专业)无人串联
- 学长学姐内推渠道弱化
- 行业人士直接对话的"破冰"门槛高

### 缺口 2:权威职业身份认证缺失
- LinkedIn 时期:`学校 + 公司 + 职位` 三角验证,可信度高
- 退出后:招聘信息真假难辨、HR 真实性无法验证
- 简历背景调查几乎中断

### 缺口 3:海归/外企人群流失
- LinkedIn 在外企圈层渗透率近 70%(退出前)
- 退出后,海归求职、外企校招的"找校友"路径断裂
- 学生失去看"业内人怎么工作"的关键信息源

### 缺口 4:行业洞察内容生态
- LinkedIn 的"专业动态 / 长文" 内容是国内职场内容先驱
- 退出后,产品经理 / 工程师 / 设计师 等垂直人群的优质内容分散在公众号、知乎、即刻、小红书
- 没有统一的"职业内容流"

## 3. 国产平台的"补位"尝试(不完美替代)

| 平台 | 定位 | 短板 |
|---|---|---|
| BOSS直聘 | 直聊招聘,适合应届生 | 社交属性弱,无校友/同事关系 |
| 智联招聘 | 老牌综合招聘 | 体验陈旧,无职业内容 |
| 前程无忧 51job | 综合性招聘,应届生求职网 | 重招聘,轻社交 |
| 脉脉 | 匿名职场社区 | 偏八卦,职业内容质量参差 |
| 小红书 | 求职经验分享 | 非职业平台,信息碎片化 |
| 知乎 | 行业问答 | 社交弱,招聘功能刚起步 |

**核心问题**:这些平台都在"工具"层补位,没有人做"职业身份 + 校友关系 + 行业内容"三合一的社交平台。

## 4. 对 AIchat-Hub 的启示

### 定位机会
> **"中国大学生自己的职业 LinkedIn"** — 用数字虚拟人作为人机交互界面,把"职业身份 / 校友网络 / 行业洞察"三件套重新连接。

### 我们的差异化
| 维度 | LinkedIn(已退) | 国产招聘工具 | **AIchat-Hub(我们)** |
|---|---|---|---|
| 关系建立 | 真人 + 弱连接 | 仅 BOSS 直聊 | **虚拟人 + 真人** 双轨 |
| 校友网络 | 强 | 无 | **强(核心卖点)** |
| 行业洞察 | 长文 / Posts | 招聘信息 | **虚拟人对话式洞察** |
| 简历辅导 | 无 | 模板 | **AI 模拟面试官 / 改简历** |
| 数据合规 | 退出的原因 | 中等 | **本地优先 + 沙箱安全** |
| 商业模式 | 订阅 / 招聘 | 招聘广告 | **免费 + 开源 + 增值** |

### 适合虚拟人形态的场景
1. **模拟面试官** — 字节/阿里/腾讯风格的 HR 数字人
2. **学长学姐** — 真人校友(经授权)的数字分身
3. **行业专家** — 算法/产品/运营/设计 的资深从业者虚拟人
4. **职业咨询师** — 霍兰德职业兴趣测试 + 职业画像的数字人引导
